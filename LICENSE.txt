三、 本地隐私与网络数据流声明 (Privacy & Network Data Flow Statement)
================================================================================
1. 默认离线与本地优先：
   - Linden Leaf 遵循本地优先（Local-First）架构原则。您的电子书文件、阅读进度、书签划线、
     想法笔记和阅读统计数据均保存在本机私有存储（IndexedDB / SQLite / 应用私有目录）中。
   - 本软件不包含任何中心化用户行为跟踪、广告推送或未经披露的遥测日志上报代码。

2. 网络请求边界与用户主动功能：
   - 启动版本更新检查（自动与手动）：
     主窗口启动约 8 秒后，应用会默认向配置的 GitHub 仓库（Releases API / 公开版本元数据）
     发起一次只读 HTTPS 请求以检查是否存在新版本；用户亦可在设置中手动检查更新。
     （卫星阅读子窗口不发起该后台更新检查。）
   - AI 辅助阅读（需用户手动配置端点与 API Key）：
     仅在用户显式触发划词提问、翻译、长文总结或润色时，将用户当前选中的文本与上下文
     通过 HTTPS 发送至用户自行配置的模型接口（如 DeepSeek、OpenAI、Ollama 等）。
   - 云端语音合成（TTS，需用户手动配置端点）：
     仅在用户选用自定义云端 TTS 接口时，将当前朗读段落文本发送至用户指定的语音端点；
     选用系统原生语音时完全使用本地操作系统 TTS 引擎。
   - WebDAV / 云盘多端同步（需用户手动配置与启用）：
     仅在用户手动触发或启用自动同步时，与用户自行配置的 WebDAV（如坚果云/Nextcloud）或
     OneDrive / Google Drive 账号通信。本地同步凭据采用操作系统安全存储（Windows DPAPI /
     Android Keystore）加密保护；网络传输通过 HTTPS/TLS 加密信道传输标准 JSON 数据，
     而非客户端端到端密文格式（请确保使用可信的 HTTPS 服务并妥善保护云端账号权限）。
   - 词库在线下载（需用户手动点击下载）：
     仅在用户手动触发“下载词库”时，通过 HTTPS 从 GitHub / jsDelivr 公开源拉取 ECDICT CSV 并在本地建库。
   - 离线 OCR 模型按需下载（需用户手动点击下载）：
     仅在用户于设置中手动点击下载 PP-OCRv6 模型时，通过 HTTPS 从 Hugging Face（或用户开启的
     国内镜像 hf-mirror.com）及 jsDelivr / unpkg 拉取 ONNX 权重与 WASM 运行时文件并校验写入应用私有目录；
     模型启用后的所有页面识别均在本地离线完成，不上传任何页面图像或书籍内容。
   - 外部浏览器 AI 伴读（Windows 可选功能，仅本机进程通信）：
     与随附 Chromium 扩展之间仅通过操作系统 Chromium Native Messaging（及必要时的 127.0.0.1 配对令牌回环）
     进行本机点对点通信，不经过任何第三方中转服务器；访问网页版 AI 服务完全遵循用户在浏览器中自行登录的会话。
   - Sign in with ChatGPT 官方登录分支（可选功能，需用户手动授权）：
     通过本机临时回环端口执行 OAuth 2.0 PKCE 授权流程直连 OpenAI 官方认证与响应接口，
     刷新令牌及访问令牌均加密保存于操作系统凭据库，绝不写入同步或备份明文。
