三、 本地隐私与网络数据流声明 (Privacy & Network Data Flow Statement)
================================================================================
1. 默认离线与本地优先：
   - Linden Leaf 遵循严格的本地优先（Local-First）架构原则。在默认配置下，您的所有电子书文件（EPUB、PDF、TXT、MOBI 等）、阅读进度、书签划线、想法笔记和阅读统计数据均完整保存在您本机的私有数据库中。
   - 本软件不包含任何中心化用户跟踪、广告推送、遥测日志上传或未经授权的数据采集代码。

2. 用户主动启用的可选网络功能：
   为满足用户的多端同步与智能化辅助需求，本软件提供了若干由用户主动配置和启用的扩展功能。启用后其数据流动边界如下：
   - AI 辅助阅读（需用户在高级设置中配置自身 API Key 或本地模型端点）：
     仅在用户显式触发划词提问、长文总结或章节润色时，将用户当前选中的文本片段通过 HTTPS 发送至用户自行填写的模型服务商 API（如 DeepSeek、OpenAI、Ollama 或兼容接口）。未经操作不自动联网。
   - 云端语音合成（TTS，需用户配置端点）：
     仅在用户选择云端 API 朗读时，将当前朗读段落的文字发送至用户指定的语音端点；若选用“系统原生语音”，则全程在 Android / Windows 操作系统内置引擎离线合成。
   - WebDAV 多端同步（需用户输入私有云盘/坚果云地址及应用密码）：
     仅在用户手动点击同步或启用定时同步时，将加密后的笔记与进度清单同步至用户本人的 WebDAV 服务器空间。凭据使用本地操作系统安全存储（Windows DPAPI / Android Keystore）加密保护。
   - 词库下载与更新检查：
     仅在用户手动点击“下载词库”或“检查更新”时，向开源分发镜像（GitHub / Gitee 官方发布通道）发起只读拉取请求。
