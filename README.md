# Linden Leaf

基于 Electron 与 Foliate 渲染引擎构建的桌面端全格式电子书阅读器。面向日常阅读与文档处理场景，提供统一排版、原位注释浮层、PDF 手绘批注及云端多端同步功能。

---

## 支持格式

- **EPUB**：支持 EPUB 2 与 EPUB 3 规范（含流式排版与固定版面）
- **Kindle 文档**：MOBI、AZW、AZW3
- **文档与文本**：PDF、TXT（支持正则表达式分章）、DOCX
- **图像与归档**：CBZ、FB2

---

## 核心功能

### 1. 阅读视图与排版控制
- **布局模式**：支持单栏/双栏分页模式与连续垂直滚动模式；支持正文字号、字重、行高、段间距、页边距及对齐方式的微调。
- **配色方案**：提供明亮、羊皮纸暖色、深灰暗色及纯黑等显示配色。
- **字体渲染**：内置开源衬线与非衬线字族，支持调用系统字体。

### 2. 注释与尾注解析
- 原生兼容标准 EPUB 脚注（`epub:type="noteref"` 与 `role="doc-noteref"`）及多看（Duokan）格式规范。
- 采用原位就近浮层展示注释文本，拦截页面跳转与跨章滚动，保持阅读进度连贯。

### 3. PDF 批注与画笔工具
- 具备自由手绘画笔、荧光笔高亮标注与笔迹橡皮擦功能。
- 标注数据本地持久化存储，页面缩放与翻页时平滑恢复。

### 4. 统计与书库管理
- **本地存储**：书籍元数据、封面图像及阅读进度通过 IndexedDB 进行本地管理。
- **数据指标**：自动统计会话时长、阅读天数及完读状态，提供日、月、年维度的图表概览。
- **书单归档**：支持自定义书单分类、待读清单与收藏夹管理。

### 5. 多端数据同步
- 支持基于 WebDAV 协议与坚果云或私有服务器进行数据同步。
- 同步范畴涵盖阅读进度、书单分类与划线笔记。

## 构建与运行

### 运行环境
- Node.js >= 18.0.0
- npm >= 9.0.0

### 开发调试
```bash
# 安装依赖
npm install

# 启动开发版
npm start
```

### 生产打包
```bash
# 打包生成 Windows 安装包及免安装绿色便携版
npm run dist
```
